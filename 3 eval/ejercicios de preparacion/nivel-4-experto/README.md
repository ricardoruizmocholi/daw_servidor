# Nivel 4 — Experto (75–100%)

## Prerequisito

Haber completado los niveles 1, 2 y 3. Especialmente:
- SOAP completo con DOMDocument (nivel 3)
- API REST CRUD completa (nivel 3)

## Ejercicios

| Archivo | Tipo | Tiempo estimado |
|---|---|---|
| `ej13_soap_con_header.php` | PHP — SOAP con Header de sesión (token) | 20 min |
| `ej14_curl_proxy.php` | PHP — cURL como intermediario entre cliente y API externa | 20 min |
| `ej15_fragmentos_dinamicos.php` | PHP — fragmentos HTML generados en servidor con filtros | 20 min |
| `ej16_simulacro_examen.md` | **Simulacro completo** — enunciado real cronometrado (90 min) | 90 min |

## Lo que debes saber al acabar este nivel

- Leer un Header SOAP con DOMXPath y validar el token antes de procesar el Body
- Hacer peticiones HTTP desde PHP con `curl_init()` / `curl_setopt()` / `curl_exec()`
- Generar fragmentos HTML (no JSON) desde PHP para inyectar con `innerHTML`
- Resolver un enunciado completo de examen de principio a fin

## Consejo para el examen

El simulacro del `ej16` simula exactamente el tipo de pregunta del trimestral.
Hazlo **sin mirar los ejemplos** de la carpeta `3 eval` — eso te dirá con precisión
dónde están tus lagunas reales. Luego compara y refuerza esos puntos.
