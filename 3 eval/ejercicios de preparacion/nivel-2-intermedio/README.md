# Nivel 2 — Intermedio (25–50%)

## Prerequisito

Haber completado Nivel 1 o tener claro:
- Status codes básicos
- Estructura del Envelope SOAP
- `header()` + `json_encode()` en PHP

## Ejercicios

| Archivo | Tipo | Tiempo estimado |
|---|---|---|
| `ej05_rest_get.php` | PHP — endpoint REST GET con filtro | 15 min |
| `ej06_soap_simple.php` | PHP — servicio SOAP que parsea y responde | 20 min |
| `ej07_pdo_consulta.php` | PHP — conexión PDO y consulta preparada | 15 min |
| `ej08_fetch_cliente.html` | HTML+JS — cliente con `fetch()` | 15 min |

## Lo que debes saber al acabar este nivel

- Cómo leer parámetros GET en PHP (`$_GET`)
- Cómo leer el body de una petición POST (`php://input`)
- Cómo parsear XML con `DOMDocument` y `DOMXPath`
- Cómo conectar a MySQL con PDO y hacer una consulta simple
- Cómo hacer una llamada REST desde JavaScript con `fetch()`
