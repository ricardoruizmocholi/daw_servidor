# Nivel 1 — Básico (0–25%)

## Antes de empezar

Si puedes responder estas tres preguntas de memoria sin mirar nada, puedes saltar al Nivel 2:

1. ¿Cuál es el status code de "recurso no encontrado"?
2. ¿Qué línea PHP necesitas antes de hacer `json_encode()`?
3. ¿Qué etiqueta obligatoria tiene todo mensaje SOAP?

Si has dudado en alguna → **empieza aquí**.
