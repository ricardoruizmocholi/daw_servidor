cURL PHP server-side — Equivalencias

Esto va en 03_curl_cliente.php. El servidor PHP actúa de cliente.

GET — equivale a fetch(url)

// GET con cURL en PHP $ch = curl_init("$urlRest/peliculas"); curl_setopt($ch, CURLOPT_RETURNTRANSFER, true); $respuesta = curl_exec($ch); $codigoHttp = curl_getinfo($ch, CURLINFO_HTTP_CODE); curl_close($ch);

POST JSON — equivale a fetch con method:POST

$json = json_encode($datos); curl_setopt($ch, CURLOPT_POST, true); curl_setopt($ch, CURLOPT_POSTFIELDS, $json); curl_setopt($ch, CURLOPT_HTTPHEADER, [ "Content-Type: application/json", "Content-Length: " . strlen($json) ]);
