Validación de Acceso a Examen

¿Qué hace este cliente?
Construye un XML SOAP con los datos del alumno y lo envía al servicio PHP. El servidor aplica las reglas de acceso y devuelve si está permitido o no. Fíjate en la diferencia entre un SOAP Fault (datos inválidos) y una respuesta negativa (datos válidos pero alumno no autorizado).
