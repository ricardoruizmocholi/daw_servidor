Biblioteca — Consulta de Préstamo

¿Qué hace este cliente?
Envía una petición SOAP al servicio de biblioteca con un token de sesión en el Header y los datos del préstamo en el Body. El servidor primero valida el token y luego consulta si el libro puede prestarse. Es el patrón "portero + servicio" que se usa en APIs reales.
